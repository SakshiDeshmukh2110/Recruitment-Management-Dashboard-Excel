# Recruitment-Management-Dashboard-Excel
Project Overview

This project is an interactive Recruitment Management Dashboard built entirely in Microsoft Excel. It helps HR and recruitment teams monitor hiring performance, candidate pipeline, recruiter productivity, offer acceptance, and overall recruitment KPIs.

The dashboard provides decision-makers with a centralized view of recruitment activities using Pivot Tables, Pivot Charts, KPI Cards, and interactive slicers.

Business Problem

Recruitment teams often manage hiring data across multiple spreadsheets, making it difficult to monitor:

Candidate pipeline
Hiring trends
Recruiter performance
Open positions
Offer acceptance
Department-wise hiring

This dashboard consolidates all recruitment information into a single interactive reporting system.

Objectives
Track recruitment KPIs
Analyze candidate sources
Monitor department hiring
Evaluate recruiter performance
Measure offer acceptance
Visualize monthly hiring trends
